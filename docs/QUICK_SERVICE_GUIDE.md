# Quick service guide

[Português do Brasil](QUICK_SERVICE_GUIDE.pt-BR.md) · [Full operator manual](OPERATOR_MANUAL.md)

## Before people arrive

- Connect the operator display and both external displays before opening
  HolyScreen.
- In **Settings > Screens**, identify every output and confirm Audience, Stage
  and Broadcast roles.
- Open one Bible verse, one image and one video in preview. Confirm image,
  audio, mute, seek and stop without sending unintended content live.
- Open the service event/playlist and verify every referenced file exists.
- Confirm the Stage clock/message and the OBS Broadcast capture when used.
- Start the local remote only on the trusted service network and test one
  harmless command.
- Create a backup after last-minute structural edits.

## During the service

- Keep Operation open and use preview before presenting unfamiliar content.
- Prefer Blackout for a temporary public hide; use Stop when the presentation
  must end.
- Watch the selected output routes before starting video.
- Do not move library files, change display cabling or install updates.
- If the remote disconnects, continue from the desktop while it reconnects.

## After the service

- Stop media and temporary overlays, then disable the remote server.
- Save reusable playlists and create a backup if content changed.
- Close the operator window and confirm HolyScreen exits.
- Record unexpected behavior and export sanitized diagnostics before changing
  the affected configuration.
