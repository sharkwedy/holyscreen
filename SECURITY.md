# Security Policy

## Supported versions

HolyScreen is currently a development preview. Security fixes are provided for
the latest published `0.10.x` release only. Older previews and unreleased builds
are not supported. This policy will be reviewed for version 1.0.

| Version | Supported |
|---|---|
| Latest `0.10.x` release | Yes |
| Older previews | No |

## Reporting a vulnerability

Do not open a public issue containing vulnerability details. Use GitHub's
private vulnerability reporting for this repository. If it is unavailable,
contact the primary maintainer through the contact information on the
[sharkwedy profile](https://github.com/sharkwedy) and request a private channel
without including sensitive details in the first message.

Include affected versions, impact, reproduction steps, and suggested mitigation.
The maintainer aims to acknowledge reports within 7 days, provide a status update
within 14 days, and coordinate disclosure after a fix is available.
