# Support

HolyScreen is maintained by volunteers and has no guaranteed response time.

- Usage questions: use GitHub Discussions when enabled.
- Reproducible defects: use the bug-report template.
- Feature proposals: use the feature-request template.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue.

Try the latest release and search existing issues first. Include the HolyScreen
version, operating system, installation method, expected and actual behavior,
logs, and minimal reproduction steps. Remove private church, member,
presentation, and media data from screenshots and logs.
