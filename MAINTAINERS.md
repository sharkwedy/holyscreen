# Maintainers

## Primary maintainer

- [sharkwedy](https://github.com/sharkwedy) — repository owner and primary maintainer.

The primary maintainer is responsible for project direction, release approval,
repository administration, security coordination, and appointing additional
maintainers.

Consistent contributors may be invited to become maintainers based on sustained
contributions, constructive participation, review quality, and care for the
community. Appointments and removals are recorded by updating this file through
a pull request.
